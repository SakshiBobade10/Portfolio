# 🌟 Personal Portfolio Website & Admin Dashboard

A full-stack dynamic portfolio website built using **Node.js, Express, EJS, and MySQL**. It features an interactive UI for users and a secure backend dashboard for managing projects, skills, certificates, and messages.

---

## ✨ Features

- 📱 **Responsive Design:** Smooth UI built with custom CSS and EJS templates.
- 🔐 **Admin Dashboard:** Secure login system to add, edit, or delete portfolio content.
- 💼 **Projects Section:** Dynamic display of portfolio projects with live links.
- 📜 **Certificates & Internships:** Showcases certifications and experience dynamically.
- 📩 **Contact Form:** Allows visitors to send messages directly from the website.

---

## 🛠️ Tech Stack

- **Frontend:** EJS (Embedded JavaScript), HTML5, CSS3, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MySQL
- **Environment Management:** dotenv
- **Email Service:** Nodemailer

---

## 💻 How to Run Locally

1. Clone the repository:
git clone https://github.com/SakshiBobade10/PORTFOLIO.git
cd PORTFOLIO

2. Install dependencies:
npm install

3. Set up Environment Variables (.env file):
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=your_password
DB_NAME=portfolio_db
PORT=8000

4. Run the application:
npm start
